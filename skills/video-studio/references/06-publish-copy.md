# Stage 5 — Publish copy, per platform

Write the copy **for the platform**, in the audience's language. A YouTube description is a search document; a TikTok caption is a hook and a conversation starter. Translating one into the other is why cross-posts underperform.

## The universal structure

Every platform gets the same four ideas, in different proportions:

1. **Promise** — what the viewer gets, in the first line.
2. **Proof / detail** — the specific thing that makes it credible.
3. **Question** — a comment prompt the viewer can answer in three words.
4. **Next step** — subscribe, follow, watch part 2, visit.

## YouTube (long-form)

| Field | Limit | What works |
|---|---|---|
| Title | 100 chars (≈60 shown) | keyword in the first 40 chars, then the specific promise |
| Description | 5,000 chars | first 2 lines appear in search — put the promise and keyword there |
| Tags | 500 chars total | 8–15 tags: exact, variants, misspellings, series name |
| Chapters | 3+ timestamps, first at 00:00 | raises session time; name them as questions |
| Pinned comment | — | ask the question you actually want answered |
| Hashtags | 3 max above the title | only if they are real search terms |

**Title formulas**
```
[Keyword]: [Specific promise] | [Audience tag]
[Number] [adjective] [noun] that [surprising result]
How [subject] [did X] without [expected cost]
Why [common belief] is wrong about [topic]
```

**Description skeleton**
```
Line 1: In this video, [audience] learns [promise] — [primary keyword].
Line 2: [Secondary keyword], stated naturally, with one concrete detail].

[2–3 sentences of unique context. What is in this video that is nowhere else.]

Chapters
00:00 [hook name]
00:24 [second beat]
...

[One-line CTA question]
[Links, credits, sources]
```

**Do not:** stuff keywords, repeat the title verbatim in line 1, use "smash that like" as the first line, or write a description that could belong to any video on the channel.

## YouTube Shorts

- **Title**: 40–60 chars, the searchable phrase first. Shorts titles are search real estate.
- **Description**: 1–2 sentences, primary keyword once, plus 3 hashtags.
- **Hashtags**: `#Shorts` plus two topical ones — beyond three is noise.
- **On-screen text** matters more than the description: the first frame's words are the thumbnail.
- **Pinned comment** is where the question lives, because Shorts viewers do not expand descriptions.

## TikTok

| Field | Limit | What works |
|---|---|---|
| Caption | 2,200 chars (≈100 shown before "more") | hook in the first 8 words |
| Hashtags | 3–5 | broad + niche + one format tag |
| On-screen text | — | carries the hook; 70%+ watch muted |

Caption skeleton:
```
[Hook, 8 words]. [One line of context]. [Question].
#topic #niche #format
```
No links in the caption. No "link in bio" unless there is one.

## Instagram Reels

- Caption limit 2,200; 3–5 hashtags beats 30 in 2026.
- First line is the only line most people see — it must work alone.
- Cover text must be readable in the **3:4 profile-grid crop**.
- Ask a question in the last line; Reels comments are a ranking signal.

## Facebook

- Reels: same vertical asset as TikTok/Shorts, but the audience skews older and shares more.
- Feed/link: 1.91:1 image, 1200×630; the first 2 lines before "See more" do the work.
- Write for **shareability**: a sentence someone would forward ("This is the clearest explanation of X I've seen").
- Native upload beats a YouTube link, always. Post the file, not the URL.

## LinkedIn

- 1200×627 thumbnail; no shouty text; the first 2 lines before "see more" decide everything.
- Professional framing: the claim, the evidence, the caveat.
- 3–5 hashtags at the end; no emoji bullets unless the brand uses them.

## X / Threads

- 280 characters; one idea; the video does the arguing.
- No hashtags unless they are a live event.

## Localisation

- Write in the audience's language, not the platform's default.
- If bilingual, put the **primary** language first and the second in the description body, not the title.
- Bengali and other non-Latin scripts: verify the font renders correctly on the thumbnail — a missing glyph becomes a box.
- Numbers, currency and dates follow the audience's convention.

## Copy audit

- [ ] First line works with everything else hidden
- [ ] Primary keyword appears once, naturally, in the first 40 characters of the title or caption
- [ ] No keyword appears more than 3 times in the whole description
- [ ] One clear question that can be answered in three words
- [ ] One next step, not four
- [ ] No "like and subscribe" as the opening line
- [ ] Spelling and names checked — a misspelled proper noun costs more than a bad adjective
- [ ] Claims match the video; no promise the video does not keep
- [ ] Every link tested
- [ ] Timestamps correct to the second (long-form)

## Publish pack deliverable

`publish-pack.md` must contain, for the chosen platform:

1. Title / caption (primary + 2 alternates for testing)
2. Description or caption body, ready to paste
3. Tags / hashtags, copy-paste ready as one line
4. Chapters, if long-form
5. Pinned comment
6. Thumbnail file name + the text that is on it
7. The one-line "why this will work" rationale
8. What to change if it underperforms in 72 hours

A pack without item 8 is incomplete — it turns the next upload into a guess.
