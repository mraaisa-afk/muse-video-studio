# Code of conduct

This project follows a simple standard.

**Be decent.** Critique the rule, the fixture, or the evidence — never the person who wrote it.

**Assume good faith and missing context.** If a contributor's rule seems wrong, it usually means they measured something you have not.

**No gatekeeping.** A first-time contributor's case card with one timestamp is worth more than a veteran's opinion.

## Not acceptable

Harassment, personal attacks, dismissive comments about someone's language or skill level, and any use of this project to generate content that harms children, deceives viewers, or infringes someone's likeness or copyright.

## Enforcement

Report problems to the maintainers by opening a private security advisory or emailing the address in the repository profile. Reports are handled confidentially. Maintainers may edit, remove, or reject contributions and comments that break this standard.
